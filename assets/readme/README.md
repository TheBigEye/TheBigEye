### About
Assets for the animated README.

| folder | what | generated by |
| --- | --- | --- |
| `live/` | 26 animated SVG cards, light + dark | `scripts/render.py` |
| `live/css/` | the same cards with their `<style>` extracted + a CSS bundle | `scripts/render.py` |
| `data/` | `telemetry.json`, the pixel-art canvas and daily history snapshots | `scripts/collect.py` |
| `image/` | the workstation photo (`pc-*.png`) and its optimised copy in `opt/` | hand-made |
| `stats/`, `header/` | **legacy** static cards, no longer referenced by the README | old workflows |

Nothing here should be edited by hand — run `python3 scripts/build.py` instead.
